# 아이템 시스템 (Item System)

## 등급 (Rarity)
1. **일반 (Common - 흰색):** 기본 장비.
2. **고급 (Uncommon - 녹색):** 소폭의 능력치 보너스.
3. **희귀 (Rare - 파란색):** 유의미한 보너스 또는 특수 효과.
4. **영웅 (Epic - 보라색):** 강력한 고유 효과.
5. **전설 (Legendary - 주황색):** 게임의 판도를 바꾸는 아티팩트.

## 분류
* **소모품:** 포션, 음식, 스크롤.
* **장비:** 무기, 방패, 갑옷, 투구, 신발, 장신구.
* **기타:** 몬스터 전리품, 제작 재료.
