# 3. 게임 디자인 (Art & Design)

## 3.1. 비주얼 컨셉 (Visual Style)

### 아트 스타일: 16-bit Retro Fantasy
- **레퍼런스**: *Stardew Valley*, *Final Fantasy VI*, *Chrono Trigger*.
- **색감**:
    - 따뜻하고 포근한 색감 (Warm Tones)을 기조로 함.
    - 숲(초록), 마을(갈색/주황), 밤(남색/보라)의 명확한 대비.
- **캐릭터**: 2등신 또는 3등신 도트 캐릭터. 감정 표현 시 말풍선 이모티콘 활용.

### UI 디자인 (User Interface)
- **소재**: 낡은 양피지, 나무 판자, 쇠사슬 등 판타지적 소재 활용.
- **레이아웃**:
    - **Top**: 현재 날짜, 시간(해/달 아이콘), AP 게이지.
    - **Center**: 메인 게임 화면 (타일맵).
    - **Bottom**: 메시지 로그 창 (TRPG 느낌), 주요 행동 단축키.
- **몰입 요소**:
    - 시스템 팝업을 최소화하고, 게임 내 오브젝트(게시판, 표지판)를 통해 정보를 전달.

## 3.2. 맵 디자인 (Map Design)

### 마을 (The Village)
- **광장**: 마을의 중심. NPC들이 모여 대화하는 장소.
- **주점(플레이어 거점)**: 플레이어가 운영하고 휴식하는 공간. 인테리어 커스텀 가능(확장 기능).
- **상점가**: 대장간, 잡화점 등.
- **마을 입구**: 외부 세계로 나가는 길(던전, 탐험).

### 탐험 구역 (확장)
- **안개 시스템 (Fog of War)**: 마을 밖은 안개로 가려져 있으며, 탐험(AP 소모)을 통해 밝혀나감.
- **절차적 생성**: 던전 내부는 입장할 때마다 구조가 조금씩 바뀜 (Roguelike 요소).

## 3.3. 인터랙션 (Interaction)

### 조작법
- **이동**: 방향키 (Arrow Keys) 또는 WASD.
- **상호작용**: Spacebar 또는 마우스 클릭.
- **메뉴**: ESC 또는 M 키.

### 대화 시스템
- NPC에게 다가가 상호작용하면 대화 모드로 진입.
- **키워드 대화**: 정해진 선택지 외에, 플레이어가 획득한 '키워드(예: 몬스터, 소문, 왕실)'를 제시하여 대화 가능.
- **AI 자유 대화**: 중요 NPC와는 텍스트 입력 또는 AI가 생성한 동적 지문을 통해 깊은 대화 가능.
