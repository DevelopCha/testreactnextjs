# 왕국 및 세력 목록 (Kingdoms & Factions)

## 에텔가르드 왕국
* **정체:** 군주제 (Monarchy)
* **특징:** 질서, 기병대, 신성 마법.
* **지도자:** 국왕 레지날 4세.
* **상징색:** 청색/금색.

## 제피르 공화국
* **정체:** 상인 공화정 / 의회 (Merchant Republic)
* **특징:** 부(Wealth), 비공정, 원소 마법.
* **지도자:** 대무역관 바리스.
* **상징색:** 백색/녹색.

## 아이언클래드 제국
* **정체:** 군사 독재 (Military Dictatorship)
* **특징:** 산업, 기술, 정복.
* **지도자:** 황제 카엘.
* **상징색:** 적색/흑색.
