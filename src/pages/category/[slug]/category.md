# 카테고리 페이지 구현

## 🎯 학습 목표
- **URL 상태 관리**: 필터/정렬 상태를 URL(`?sort=price_asc`)에 저장하여 공유 가능하고 새로 고침 시에도 유지되도록 합니다.
- **클라이언트 측 필터링**: URL 매개변수를 기반으로 `useMemo`를 사용하여 데이터를 필터링하고 정렬합니다.
- **Shallow Routing**: 전체 페이지 새로 고침 없이 URL을 업데이트하기 위해 `router.push`를 사용합니다(Next.js가 최적화된 전환을 처리함).

## 🛠️ 구현 로직
1. **매개변수**: `router.query`에서 `slug`와 `sort`를 추출합니다.
2. **필터링**: 슬러그와 일치하는 카테고리로 전체 제품 목록을 필터링합니다.
3. **정렬**: `sort` 매개변수를 기반으로 필터링된 목록을 정렬합니다.
4. **상호작용**: 선택 상자를 변경하면 URL 쿼리 매개변수가 업데이트됩니다.

## 💡 팁
- 대규모 데이터 세트의 경우 필터링/정렬은 서버에서 수행해야 합니다. 작은 데이터 세트(이 모의 데이터와 같은)의 경우 클라이언트 측이 더 빠르고 즉각적인 피드백을 제공합니다.
- 항상 "결과 없음" 케이스를 처리하세요.
