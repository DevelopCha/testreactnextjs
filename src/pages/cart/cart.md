# 장바구니 페이지 구현

## 🎯 학습 목표
- **낙관적 업데이트**: React Query의 `onMutate`를 사용하여 서버 응답이 도착하기 *전에* UI를 업데이트하여 앱이 즉각적으로 반응하는 것처럼 느끼게 합니다.
- **롤백 로직**: `onError`를 사용하여 오류 발생 시 이전 상태로 롤백합니다.
- **캐시 무효화**: 뮤테이션이 완료된 후 데이터 일관성을 보장하기 위해 `invalidateQueries`를 사용합니다.

## 🛠️ 구현 로직
1. **가져오기**: `useQuery`로 장바구니 항목을 로드합니다.
2. **뮤테이션**: `useMutation`으로 수량 업데이트를 처리합니다.
3. **낙관적 UI**:
   - `onMutate`: 기존 쿼리를 취소하고, 상태 스냅샷을 찍고, 캐시를 수동으로 업데이트합니다(`setQueryData`).
   - `onError`: 스냅샷을 복원합니다.
   - `onSettled`: 실제 서버 상태를 다시 가져옵니다.

## 💡 팁
- 낙관적 업데이트는 장바구니 수량과 같은 "카운터" UI에 필수적입니다.
- 경쟁 조건을 방지하기 위해 캐시를 수동으로 업데이트하기 전에 항상 진행 중인 쿼리를 취소(`cancelQueries`)하세요.
