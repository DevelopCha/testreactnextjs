# 주문 내역 페이지 구현

## 🎯 학습 목표
- **중첩 매핑**: 주문 목록 렌더링, 각 주문에는 항목 목록이 포함됨(`orders.map` -> `order.items.map`).
- **조건부 UI**: 주문 상태(`paid`, `shipping` 등)에 따라 다른 배지 렌더링.
- **날짜 포맷팅**: `toLocaleDateString`을 사용하여 ISO 날짜 포맷팅.

## 🛠️ 구현 로직
1. **가져오기**: 모든 주문을 로드합니다.
2. **외부 루프**: 각 주문에 대한 주문 카드를 렌더링합니다.
3. **내부 루프**: 해당 주문의 각 제품에 대한 목록 항목을 렌더링합니다.
4. **상태 배지**: 상태 문자열에 따라 Tailwind 스타일의 span을 반환하는 헬퍼 함수.

## 💡 팁
- 맵 내부에서 매핑할 때 내부 키가 외부 컨텍스트와 상대적으로 고유하거나 전역적으로 고유한지 확인하세요.
- `getStatusBadge`와 같은 작은 UI 헬퍼를 추출하면 JSX를 깔끔하게 유지할 수 있습니다.
