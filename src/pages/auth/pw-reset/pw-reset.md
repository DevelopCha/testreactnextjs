# 비밀번호 재설정 페이지 구현

## 🎯 학습 목표
- **비동기 UI 상태**: `idle`, `loading`, `success`, `error` 상태를 명시적으로 관리.
- **조건부 렌더링**: 현재 상태(폼 vs 성공 메시지)에 따라 다른 UI 블록 표시.
- **오류 시뮬레이션**: 오류 처리 UI를 보여주기 위해 무작위로 오류 발생.

## 🛠️ 구현 로직
1. **상태 관리**: `useState`를 사용하여 요청 상태 추적.
2. **시뮬레이션**: `setTimeout`으로 네트워크 지연 시뮬레이션. `Math.random()`으로 가끔 실패 시뮬레이션.
3. **피드백**:
   - **로딩**: 입력 및 버튼 비활성화.
   - **성공**: 폼을 성공 메시지로 대체.
   - **오류**: 오류 배너 표시.

## 💡 팁
- 여러 개의 불리언 플래그(`isLoading`, `isError`, `isSuccess`)보다 명시적인 상태 머신(예: `"idle" | "loading"`)이 종종 더 좋습니다.
