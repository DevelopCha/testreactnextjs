# 회원가입 페이지 구현

## 🎯 학습 목표
- **복잡한 유효성 검사**: Zod `regex`와 `refine`을 사용하여 비밀번호 복잡성 및 확인 일치 검사.
- **Mock API 상호작용**: 모의 백엔드로 POST 요청 전송.
- **사용자 피드백**: 성공 시 `alert` 및 탐색 사용.

## 🛠️ 구현 로직
1. **스키마**: 엄격한 비밀번호 규칙(regex) 정의 및 `.refine()`을 사용하여 `password === confirmPassword` 확인.
2. **API 호출**: 인메모리 DB에 사용자를 추가하는 것을 시뮬레이션하는 `apiClient.post("users", ...)` 호출.
3. **오류 처리**: 오류를 포착하고 루트 폼 오류 설정.

## 💡 팁
- `refine`은 교차 필드 유효성 검사에 강력합니다.
- 비밀번호 복잡성 규칙은 사용자가 입력하기 전에 명확하게 전달되어야 합니다.
