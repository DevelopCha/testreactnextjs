# 프로필 편집 페이지 구현

## 🎯 학습 목표
- **폼 미리 채우기**: 기존 데이터로 폼을 채우기 위해 `useEffect`와 `setValue`를 사용합니다.
- **읽기 전용 필드**: 편집할 수 없어야 하는 필드(예: 이메일) 처리.
- **Context 업데이트**: 성공적인 API 업데이트 후 새로 고침 없이 변경 사항을 즉시 반영하기 위해 전역 `AuthContext`를 업데이트합니다.

## 🛠️ 구현 로직
1. **초기화**: `useEffect`는 `state.user`를 감시하고 사용 가능할 때 폼 값을 업데이트합니다.
2. **제출**: API 업데이트를 전송(시뮬레이션)한 다음 `login()`(클라이언트 측 상태를 업데이트하는 `setUser` 역할)을 호출합니다.
3. **탐색**: 성공 시 `/mypage`로 리다이렉트합니다.

## 💡 팁
- React Hook Form에서 `defaultValues`는 초기 로드에 좋지만, 데이터가 비동기적으로 오는 경우(Context나 Query처럼) `useEffect` + `setValue`(또는 `reset`)가 종종 필요합니다.
