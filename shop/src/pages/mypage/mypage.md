# 마이 페이지 구현

## 🎯 학습 목표
- **보호된 경로**: 로그인한 사용자만 액세스할 수 있도록 `AuthGuard`로 페이지를 감쌉니다.
- **데이터 가져오기**: `AuthContext`의 ID를 기반으로 최신 사용자 데이터를 가져오기 위해 `useQuery`를 사용합니다.
- **조건부 렌더링**: 로딩 상태(주로 AuthGuard에서 처리됨) 및 빈 상태 처리.

## 🛠️ 구현 로직
1. **인증 확인**: `AuthGuard`는 인증되지 않은 경우 리다이렉트합니다.
2. **쿼리**: `useQuery(["user", id])`는 최신 사용자 세부 정보를 가져옵니다. `enabled: !!state.user`는 ID가 있을 때만 실행되도록 보장합니다.
3. **레이아웃**: 프로필 카드와 대시보드 통계를 분리하는 그리드 레이아웃.

## 💡 팁
- Context에 사용자 데이터가 있더라도 프로필 페이지에서 최신 데이터를 가져오는 것은 서버와의 동기화를 보장하는 좋은 방법입니다.
