# 주문 결과 페이지 구현

## 🎯 학습 목표
- **캐시 무효화**: `queryClient.invalidateQueries`를 사용하여 장바구니와 주문 내역을 강제로 다시 가져와 UI가 새로운 상태(빈 장바구니, 새 주문)를 반영하도록 합니다.
- **피드백 루프**: 명확한 성공 피드백과 탐색 옵션 제공.

## 🛠️ 구현 로직
1. **무효화**: 마운트 시 `["cart"]`와 `["orders"]`를 무효화합니다. 이렇게 하면 사용자가 다음 페이지로 이동할 때 최신 데이터를 얻을 수 있습니다.
2. **UI**: 링크가 포함된 간단한 성공 메시지.

## 💡 팁
- 여러 리소스(장바구니, 주문, 재고)에 영향을 미치는 "주문하기"와 같은 복잡한 상태 변경의 경우 수동으로 캐시를 업데이트하는 것보다 무효화가 더 안전합니다.
