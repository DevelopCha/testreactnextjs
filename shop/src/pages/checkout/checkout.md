# 체크아웃 페이지 구현

## 🎯 학습 목표
- **다단계 폼**: 단일 폼 컨텍스트를 유지하면서 여러 시각적 단계(`배송` -> `결제`)에 걸쳐 폼 상태를 관리합니다.
- **세션 지속성**: 사용자가 실수로 새로 고침하더라도 진행 상황을 잃지 않도록 `sessionStorage`를 사용하여 폼 데이터를 저장합니다.
- **Form Watch**: 지속성 및 조건부 렌더링을 위해 폼 변경 사항을 구독하기 위해 `watch`를 사용합니다.

## 🛠️ 구현 로직
1. **단계**: `step` 상태는 폼의 어느 부분이 보이는지 제어합니다.
2. **지속성**:
   - `useEffect` (마운트): `sessionStorage`를 확인하고 `setValue`를 호출하여 데이터를 복원합니다.
   - `useEffect` (watch): 변경 사항을 구독하고 `sessionStorage`에 저장합니다.
3. **제출**:
   - 1단계: 유효성을 검사하고 2단계로 이동합니다.
   - 2단계: API에 주문을 제출하고 스토리지를 지웁니다.

## 💡 팁
- `sessionStorage`는 탭이 닫히면 지워지므로 임시 트랜잭션 데이터에 적합합니다. `localStorage`는 이 사용 사례에 너무 오래 지속될 수 있습니다.
