# 로그인 페이지 구현

## 🎯 학습 목표
- **React Hook Form**: 폼 상태 및 제출 관리.
- **Zod 통합**: 스키마 기반 유효성 검사.
- **Auth Context**: 전역 인증 상태 업데이트.
- **리다이렉트 로직**: `redirect` 쿼리 파라미터 처리.

## 🛠️ 구현 로직
1. **스키마 정의**: `zod` 스키마로 이메일 및 비밀번호 규칙 정의.
2. **폼 훅**: `useForm`과 `zodResolver`를 사용하여 스키마 연결.
3. **제출**: `onSubmit`에서 API 호출 시뮬레이션 및 `AuthContext` 업데이트.
4. **리다이렉트**: `router.query.redirect`를 확인하여 사용자를 이전 페이지로 이동.

## 💡 팁
- 중복 제출을 방지하기 위해 항상 `isSubmitting` 상태를 사용하세요.
- 실제 앱에서는 입력 필드 외의 클라이언트 측에서 비밀번호를 평문으로 다루지 마세요.
- 서버 측 유효성 검사 오류(예: 잘못된 자격 증명)에는 `setError("root")`를 사용하세요.
