# 이벤트 목록 페이지 (SSR)

## 🎯 학습 목표
- **서버 사이드 렌더링 (SSR)**: 모든 요청마다 데이터를 가져오기 위해 `getServerSideProps`를 사용합니다.
- **SEO 친화적**: 콘텐츠가 서버에서 렌더링되므로 검색 엔진 크롤러가 즉시 볼 수 있습니다.

## 🛠️ 구현 로직
1. **getServerSideProps**: 모든 요청에 대해 서버에서 실행됩니다.
2. **데이터 가져오기**: API 호출을 시뮬레이션합니다(500ms 지연).
3. **Props**: 가져온 `events` 배열을 컴포넌트 props로 전달합니다.
4. **렌더링**: 컴포넌트는 `useQuery`나 `useEffect`가 아닌 props로 데이터를 받습니다.

## 💡 팁
- 데이터가 자주 변경되고 SEO를 위해 최신 상태여야 하는 경우(예: 주가, 뉴스 피드) SSR을 사용하세요.
- 서버가 HTML을 보내기 전에 가져오기를 완료해야 하므로 SSR은 TTFB(Time to First Byte)에 지연 시간을 추가합니다.
