# 이벤트 상세 페이지 (SSG)

## 🎯 학습 목표
- **정적 사이트 생성 (SSG)**: `getStaticProps` 및 `getStaticPaths`를 사용하여 빌드 시 페이지를 미리 렌더링합니다.
- **증분 정적 재생성 (ISR)**: 전체 다시 빌드 없이 주기적으로 정적 페이지를 업데이트하기 위해 `revalidate`를 사용합니다.
- **폴백 처리**: 빌드 시 생성되지 않은 경로에 대한 `router.isFallback` 상태를 처리합니다.

## 🛠️ 구현 로직
1. **getStaticPaths**: 미리 렌더링할 ID 목록을 반환합니다.
2. **getStaticProps**: 빌드 시 특정 ID에 대한 데이터를 가져옵니다.
3. **ISR**: `revalidate: 60`은 데이터가 변경되면 60초 후에 백그라운드에서 페이지가 업데이트되도록 보장합니다.

## 💡 팁
- SSG는 HTML이 CDN에서 제공되므로 가장 빠른 렌더링 방법입니다.
- 사용자별로 데이터가 변경되지 않는 마케팅 페이지, 블로그 게시물 및 문서에 SSG를 사용하세요.
