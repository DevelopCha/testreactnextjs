# 제품 상세 페이지 구현

## 🎯 학습 목표
- **동적 라우팅**: `useRouter`를 사용하여 URL 매개변수 `id`에 액세스.
- **파생 상태**: `useMemo`를 사용하여 선택한 옵션과 수량을 기반으로 총 가격 계산.
- **대화형 UI**: 옵션 선택 및 수량 업데이트 처리.

## 🛠️ 구현 로직
1. **라우팅**: `src/pages/product/[id]/index.tsx`는 `/product/1`, `/product/2` 등에 매핑됩니다.
2. **데이터 가져오기**: ID를 사용하여 제품 세부 정보를 가져옵니다.
3. **가격 계산**: `useMemo`는 `selectedOption` 또는 `quantity`가 변경될 때마다 가격을 다시 계산합니다.
4. **장바구니 로직**: 장바구니에 추가하기 전에 인증을 확인합니다(시뮬레이션).

## 💡 팁
- `useMemo`는 모든 렌더링에서 불필요한 재계산을 방지하는 데 중요합니다. 간단한 수학은 저렴하지만 더 복잡한 로직에는 좋은 패턴입니다.
- 제출하기 전에 항상 입력(선택한 옵션 등)의 유효성을 검사하세요.
